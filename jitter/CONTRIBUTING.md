# Contributing to Jitter

Thank you for your interest in contributing to Jitter.

## Development Workflow

1. Fork and clone the repository.
2. Install with development dependencies:
   ```bash
   pip install -e ".[dev]"
   ```
3. Run linting, typing, and test suites prior to submitting a PR:
   ```bash
   ruff check .
   ruff format --check .
   mypy --strict src
   pytest
   ```

## Development Guidelines

- **Zero Fabricated Numbers**: All metrics, benchmark figures, and accuracy estimates must be generated by automated scripts.
- **Pure Logic vs. I/O**: Keep statistical and diagnostic engines pure and free from filesystem, network, or device side-effects.
- **Reproducibility**: All synthetic generators and bootstrap resamplers require explicit random seeds.
- **Type Annotations**: All code in `src/` must be strictly typed and pass `mypy --strict`.
